# 抽象代数（Abstract Algebra / 近世代数）

> 一句话定位：把初等代数中的"加法、乘法规律"公理化成群、环、域三大结构，研究所有代数系统共有的骨架——是现代代数（交换代数、表示论、代数数论、代数几何）的共同语言。

## 一、课程大纲
通常**一学期**开设：

- 群：群公理（结合律、单位元、逆元）、阶、循环群、子群与陪集。
- 同态与同构：$\varphi(ab)=\varphi(a)\varphi(b)$、Cayley 定理、正规子群与商群。
- Lagrange 定理：$|G|=|H|\cdot[G:H]$，及 Euler 定理与 Fermat 小定理。
- 群作用：轨道-稳定子定理、Burnside 引理、Sylow 定理。
- 环：整数、多项式、矩阵的共性抽象；理想 $(a)$、商环、同态基本定理。
- 整环与因子分解：唯一分解（UFD）、主理想整环（PID）、Euclid 整环（ED）。
- 多项式环：$F[x]$、不可约多项式、$F[x]/(f(x))$ 构造扩域。
- 域与域论：素域、有限域 $\mathbb{F}_{p^n}$、扩域次数 $[F:K]$、分裂域与正规扩张。
- Galois 理论初步：Galois 群与方程的可解性（五次方程无解的幕后原理）。
- 模与线性代数的重访（选讲）：主理想整环上的模与 Jordan 标准形。

## 三、知识脉络
高等代数（向量空间、矩阵、特征值、同构）→ **抽象代数**：

$$\text{群公理} \Rightarrow \text{子群与商群} \Rightarrow \text{同态基本定理} \Rightarrow \text{环与理想} \Rightarrow \text{多项式与扩域 } F[x]/(f) \Rightarrow \text{有限域 } \mathbb F_{p^n} \Rightarrow \text{Galois 群}$$

→ 后续课程：
- 硕博·交换代数（环论 + 公式求值的完整性、Noetherian 环、局部化）。
- 硕博·表示论（群线性 / 投影表示，矩阵群的分析子研究）。
- 硕博·代数数论（$\mathbb{Q}[\sqrt d]$、整环扩张与素理想）。
- 编码 / 密码：有限域 $\mathbb F_{2^n}$ 是 AES、ECC、BCH 等标准的地基。
- 组合论 / 图论：对称群 $S_n$ 之上的群作用技术。

## 五、核心概念解释
**1. 群的定义**：非空集合 $G$ 与二元运算 $\cdot$ 满足：

$$\begin{aligned}
&\text{(1) 结合律：} && (a b) c = a (b c);\\
&\text{(2) 单位元：} && \exists e,\ ea=ae=a;\\
&\text{(3) 逆元：} && \forall a,\ \exists a^{-1},\ aa^{-1}=a^{-1}a=e.
\end{aligned}$$

**2. Lagrange 定理**：有限群 $G$，子群 $H$ 的阶整除 $G$ 的阶：

$$|G|=|H|\cdot[G:H] .$$

素数阶群必为循环群（这一结论简单但力量巨大）。

**3. 环与理想**：$R$ 含加法交换群与分配的乘法；理想 $I\le R$ 使 $R/I$ 仍成环：

$$\mathbb Z/n\mathbb Z=\mathbb Z_n .$$

**4. Euler / Fermat 小定理**：若 $(a,n)=1$ 则：

$$a^{\phi(n)}=1 \pmod{n},\qquad p \text{ 为素数时 } a^{p-1}=1 \pmod p .$$

RSA 公钥的解密关系 $\mathrm{e}\cdot\mathrm{d}\equiv1 \pmod{\phi(n)}$ 的钥匙就在于此。

**5. 有限域的存在与唯一**：

$$\mathbb F_{p^n}\ \text{存在且互相同构（唯一）}.$$

限制性是需要 $p$ 等幂，直接支撑 AES / ECC / 编码理论。取 $\mathbb F_4=\{0,1,\alpha,\alpha+1\}$（$\alpha^2+\alpha+1=0$）。

**6. Galois 群与方程可解性**：

$$\mathrm{Gal}(L/K)=\{\sigma\in \mathrm{Aut}(L):\sigma\vert_K=\mathrm{id}\} .$$

正对应着"方程根的一般对称性"，可解性等同于其 Galois 群为可解群，从而证明五次方程无一般根式解（Abel-Ruffini + Galois）。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 密码学 | RSA（$n=pq$ 的模运算） | 使用 $\mathbb Z_n^*$ 的 Euler 定理 + 大整数分解困难性 |
| 密码学 | ECC 椭圆曲线加密 | 曲线上的点成有限交换群，基本模型：$y^2=x^3+ax+b$ |
| 编码理论 | BCH / Reed–Solomon 码 | 有限域 $\mathbb F_{2^n}$ / 多式环 $GF(256)$ 用于 QR 码、SSD、纠删码 |
| 编译器 | SSA 表格 / 分析 类别的格论代数 | 帧格 / 格结构上的常量传播 / 数据流分析 |
| 计算机视觉 | 群论式变换（$SO(3)$ / $SE(3)$） | 利用旋转 / 平移群的对称性做等变网络与姿态估计 |
| 组合计数 | Pólya 定理 / Burnside 引理 | 化学分子、图形着色、等构计数的经典工具 |
