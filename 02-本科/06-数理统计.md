# 数理统计（Mathematical Statistics）

> 一句话定位：概率论的"逆向工程"课——已知样本数据，反推总体的分布与参数，是所有数据分析、机器学习评估方法（假设检验 / 置信区间 / 回归）的共同数学语言。

## 一、课程大纲
通常**一学期**开设：

- 总体与样本：总体 $X\sim F(x,\theta)$，简单随机样本 $(X_1,\dots,X_n)$ i.i.d.。
- 统计量与抽样分布：样本均值 $\bar X$、样本方差 $S^2$；三大分布 $\chi^2$、$t$、$F$。
- 点估计：矩估计法、最大似然估计 MLE $\hat\theta_{\mathrm{MLE}}=\arg\max_\theta \sum_{i}\log f(x_i;\theta)$。
- 估计量评价准则：无偏性 $\mathrm E[\hat\theta]=\theta$、有效性、一致性；Rao–Cramér 下界 $\operatorname{Var}(\hat\theta)\ge \dfrac{1}{n I(\theta)}$、Fisher 信息。
- 区间估计：置信区间 $[\hat\theta_L,\hat\theta_U]$、单 / 双侧置信水平。
- 假设检验：$H_0$ / $H_1$、检验统计量、显著水平 $\alpha$、两类错误、p 值、势函数（Power）。
- 正态总体参数检验：$u$ 检验、$t$ 检验、$\chi^2$ 检验、$F$ 检验。
- 非参数拟合检验：$\chi^2$ 拟合优度检验、Kolmogorov–Smirnov 检验。
- 线性回归初步：最小二乘 $\hat\beta=(X^{\mathsf T}X)^{-1}X^{\mathsf T}y$，回归假设与诊断。
- 方差分析（ANOVA）与多因子分析简介。

## 三、知识脉络
概率论（数学分析 / 度量积分）→ **数理统计**：

$$\text{i.i.d. 样本 } (X_1,\dots,X_n) \Rightarrow \text{抽样分布 } \bar X,S^2 \Rightarrow \text{点估计（MLE）} \Rightarrow \text{无偏/一致性与 Rao–Cramér} \Rightarrow \text{置信区间} \Rightarrow \text{假设检验（p 值 / 势）} \Rightarrow \text{回归与 ANOVA}$$

→ 后续课程：
- 随机过程（数据的密度平稳性检验依赖贝叶斯推断与时间序列前奏）。
- 硕博·渐近统计 / 数理统计：MLE 一致性 $\hat\theta_{\mathrm{MLE}}\xrightarrow{P}\theta_0$ 与渐近正态 $\sqrt n(\hat\theta-\theta_0)\xrightarrow{d}N(0,\ I(\theta_0)^{-1})$。
- 硕博·数理机器学习（Efron–Tibshirani 大包理论，高维统计 / sparsity）。
- 机器学习评估（ROC、AUC、交叉验证、p 值修正）也是本课的工程大众化。

## 五、核心概念解释
**1. 正态总体两大统计量**（样本均值 $\bar X$ 与样本方差 $S^2$，后接转换分布）：

$$\frac{\bar X-\mu}{S/\sqrt n}\sim t_{n-1}.$$

小样本下未知 $\mu,\sigma$ 时合理使用这一统计与自由度 $n-1$。

**2. 最大似然估计**：似然函数 $L(\theta)=\prod_{i=1}^n f(x_i;\theta)$，求 $\hat\theta=\arg\max_\theta \log L(\theta)$。例如 iid. 指数分布 $f(x;\lambda)=\lambda \mathrm e^{-\lambda x}$：

$$L(\lambda)=\lambda^n \mathrm e^{-\lambda\sum x_i}\ \Rightarrow\ \hat\lambda_{\mathrm{MLE}}=\bar X^{-1}.$$

**3. Rao–Cramér 下界**：任何无偏估计的方差下界 ---- (期望 Fisher 信息倒数)：

$$\operatorname{Var}(\hat\theta)\ \ge\ \frac{1}{n\,I(\theta)} .$$

为估计质量给出了"测速上限"，定义了有效估计量。

**4. 假设检验的基本逻辑**：原假设 $H_0$ 下统计量 $T$ 的分布已知，若 $|T|>c_\alpha$（拒收因子）则拒绝 $H_0$：

$$P_{H_0}\{|T|>c_\alpha\}=\alpha .$$

其中 p 值是"更极端"的概率：

$$p=P_{H_0}\{|T^*|\ge |T_{\text{obs}}|\} .$$

**5. 正态总体的参数假设检验示例**（$t$ 检验，单侧）：

$$H_0:\mu=\mu_0,\qquad T=\frac{\bar X-\mu_0}{S/\sqrt n}\sim t_{n-1}.$$

**6. 线性回归的最小二乘估计**：

$$\hat\beta=(X^{\mathsf T}X)^{-1}X^{\mathsf T}\bm y .$$

在正态噪声 $y=X\beta+\epsilon\ (\epsilon\sim N(\bm 0,\sigma^2I))$ 假设下还是 MLE，在高斯-马可夫假设下是 BLUE。
