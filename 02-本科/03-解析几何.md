# 解析几何（Analytic Geometry）

> 一句话定位：用坐标与向量使几何问题代数化、代数问题几何可视化的入门课，通常与数学分析、高等代数在大一并开，为学生建立"数形结合"的思维方式。

## 一、课程大纲
通常**一学期**开设：

- 空间向量与坐标运算：向量加法、数乘、点积、叉积，建立三维解构思想。
- 平面与直线：法向量 $\bm n$、点法式方程、直线参数方程。
- 空间曲面：球面、柱面、锥面、旋转曲面的生成方程。
- 二次曲面与曲线分类：椭球面、单叶 / 双叶双曲面、抛物面、马鞍面 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=2cz$。
- 一般二次曲面的化简：通过正交变换（旋转）消去叉乘项。
- 坐标变换：平移 $x = x_0 + t\vec v$ 、旋转矩阵 $R$，欧拉角。
- 曲面参数化：把曲面转化成 $\bm r(u,v)$ 表示。(（为微分几何作铺垫）

## 三、知识脉络
高中平面解析几何（直线 / 圆锥曲线）→ **解析几何**：

$$\text{向量与坐标} \Rightarrow \text{直线/平面方程} \Rightarrow \text{二次曲面分类} \Rightarrow \text{坐标变换与正交矩阵} \Rightarrow \text{曲面参数化 } \bm r(u,v)$$

→ 后续课程：
- 微分几何（同为"曲线曲面"，但开始用微积分 $\dot{\bm r}$、二阶导数研究局部弯曲）→ 硕博·黎曼几何。
- 高等代数（曲面分类的实质是二次型的化简，即对称矩阵的特征值分解 $A\bm x = \lambda$ 之几何版本）。
- CAGD / 计算机图形学（Bézier曲面、透视投影都建立在坐标变换上）。

## 五、核心概念解释
**1. 直线与平面的关系（工程基础）**：过点 $\bm p_0$、以 $\bm v$ 为方向的直线，以 $\bm n$ 为法向量的平面：

$$\bm p(t)=\bm p_0+t\bm v,\qquad \bm n\cdot(\bm x-\bm p_0)=0 .$$

**2. 椭球面**：由可压缩半径定义旋转对称曲面：

$$\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1 .$$

**3. 螺旋线（Helix）**：参数化：

$$\bm r(t)=(a\cos t,\ a\sin t,\ bt) .$$

是曲率 + 挠率的最经典代表例子，为微分几何的 Frenet 公式做准备。

**4. 二次曲面化简**：原式含交叉项 $x^{\mathsf T}A\bm x$，可用正交变换 $\bm x=Q\bm y$（$Q$ 列为 $A$ 的标准正交特征向量）化为对称轴对齐形式：

$$\bm x^{\mathsf T}A\bm x = \sum_i \lambda_i y_i^2 .$$

**5. 混合积与体积**：三个向量的混合积的绝对值是平行六面体体积：

$$|\bm a\cdot(\bm b\times\bm c)|=V .$$

是计算机图形学判断点在四面体内外、凸包算法的钥匙。
