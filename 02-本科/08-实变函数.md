# 实变函数（Real Analysis / Measure Theory 引入）

> 一句话定位：把 Riemann 积分升级为 Lebesgue 积分，引入测度与 $\sigma$-代数，突破极限交换的限制——是从"具体计算"进入"抽象分析"的关键桥梁课。

## 一、课程大纲
通常**一学期**开设：

- 集合与基数：等势、可数集与不可数集、$\mathbb R\not\cong\mathbb N$（对角线法）。
- 点集：开 / 闭集、完全集、聚点、$\mathbb R^n$ 中集合的构造与 Borel 集。
- Lebesgue 测度 $m(A)$：外测度、Carathéodory 可测条件、零测集。
- 可测函数：可测集上的定义域、基本性质，Egorov / Lusin 定理。
- Lebesgue 积分：简单函数逼近、$\int f\,dm$、单调收敛定理（MCT）与 Fatou 引理。
- 控制收敛定理：在 $\lvert f_n\rvert\le g\in L^1$ 下 $\int f_n \to \int f$。
- $L^p$ 空间初步：范数 $\|f\|_p$、Hölder / Minkowski 不等式、完备性（Riesz–Fischer）。
- 微分与不定积分：绝对连续函数、Newton–Leibniz 公式的正确表述。
- Riemann-Stieltjes 积分与 Lebesgue-Stieltjes 积分（选讲）。

## 三、知识脉络
数学分析（Riemann 积分 + 点态收敛）→ **实变函数**：

$$\text{基数与点集} \Rightarrow \text{Lebesgue 测度 } m(A) \Rightarrow \text{可测函数} \Rightarrow \text{Lebesgue 积分 } \int f\,dm \Rightarrow \text{单调 / 控制收敛定理} \Rightarrow L^p \text{ 空间} \Rightarrow \text{绝对连续函数与牛顿–莱布尼茨}$$

→ 后续课程：
- 测度论与实分析（硕博，严格展开）。
- 泛函分析：$L^p$ 空间的完备性导致 Banach / Hilbert 大理论。
- 概率论：用测度论的语言重新描述（测度=概率测度 $P$、随机变量=可测函数）。
- 偏微分方程：Sobolev 空间 / 弱解直接建立在勒贝格积分与 $L^p$ 之上。
- 调和分析：Fourier 变换的严格化、Parseval 与 $L^2$ 理论。

## 五、核心概念解释
**1. Lebesgue 测度**：对单点集 $m(\{x\})=0$，对区间 $m((a,b))=b-a$，对一般集合通过外测度 + Carathéodory 条件定义：

$$m^*(A)=\inf\left\{\sum_{k}\mathrm{len}(I_k)\ :\ A\subseteq\bigcup\nolimits_k I_k\right\}.$$

区间 $[0,1]$ 的测度是 $1$，但其内有理数集 $\mathbb{Q}\cap[0,1]$ 测度为 $0$——测度"数体积"而非"数点"。

**2. 简单函数逼近与 Lebesgue 积分**：

$$\int f\,dm=\sup_{\varphi\le f,\ \varphi \text{ 简单}} \int \varphi\,dm .$$

先把"面积"在阶梯函数上看清楚，再通过单调极限扩展到一般可测函数。

**3. 单调收敛定理（MCT）**：

$$0\le f_1\le f_2\le \cdots\to f \quad \Longrightarrow\quad \int f_n\,dm\to \int f\,dm.$$

**4. 勒贝格控制收敛定理（DCT）**：

$$\text{若 } |f_n|\le g,\ g\in L^1,\ \text{则}\quad \lim_{n\to\infty}\int f_n\,dm=\int\lim_{n\to\infty}f_n\,dm .$$

是"什么时候极限穿过积分"的最终答案，几乎包揽所有应用。

**5. 期望 = Lebesgue 积分**：概率论中

$$\mathrm E[X]=\int_\Omega X\,dP,\qquad \mathrm E[Y\mid X]=\text{条件期望（对 }\sigma(X)\text{ 可分解）}.$$

期望本质上是"随机变量 $X$ 相对于概率测度 $P$ 的积分"。

**6. Riemann 与 Lebesgue 的关系**（Lebesgue 判据）：

$$f \text{（在闭区间上）Riemann 可积} \iff f \text{ 有界且间断点集是零测集} .$$

这一判据说明 Riemann 可积 function 的"坏点"必须足够稀疏——它同时给出 Riemann 积分的局限与 Lebesgue 积分的适用范围。
