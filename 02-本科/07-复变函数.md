# 复变函数（Complex Analysis）

> 一句话定位：把数学分析的极限、积分、级数搬到复平面 $\mathbb{C}$ 上；复可导（全纯）条件的强约束带来积分 / 级数 / 留数理论的大爆炸，是分析学最具美感的一门课。

## 一、课程大纲
通常**一学期**开设：

- 复数与复平面：辐角与极坐标表示 $z=r\mathrm e^{i\theta}$、Riemann 球面模型。
- 解析函数与全纯性：导数定义 $f'(z)=\lim_{\Delta z\to 0}\frac{f(z+\Delta z)-f(z)}{\Delta z}$、Cauchy–Riemann 条件。
- 初等函数：$\mathrm e^z$、$\log z$（多值性）、三角 / 双曲函数。
- 复积分：$\oint_C f(z)\,dz$、柯西积分定理（沿闭曲线积分为零）。
- 柯西积分公式与高阶导数公式：$f^{(n)}(a)=\dfrac{n!}{2\pi i}\oint_C \dfrac{f(z)}{(z-a)^{n+1}}dz$。
- 解析函数积分学结果：Morera 定理、Liouville 定理、最大模原理。
- 幂级数展开：Taylor 级数与 Laurent 级数。
- 留数定理与积分计算：$\mathrm{Res}_{z=a} f$，实积分 $\int_{-\infty}^{+\infty}R(x)\,dx$ 的求值。
- 保角映射：Möbius 变换、Schwarz–Christoffel（进阶）。
- 单叶函数、Riemann 面初步（选讲）。

## 三、知识脉络
数学分析（一元微积分）→ **复变函数**：

$$\text{全纯 } f(z) \Rightarrow \text{Cauchy–Riemann 方程} \Rightarrow \text{柯西积分定理} \Rightarrow \text{柯西积分公式 / 导数展开} \Rightarrow \text{Laurent 级数与留数} \Rightarrow \text{保角映射}$$

→ 后续课程：
- 偏微分方程（二维 Laplace $\Delta u=0$ 的转化）。
- 微分几何（复结构、Riemann 面）→ 硕博·复几何 / 曲面理论。
- 硕博·解析数论（Riemann ζ 函数 $\zeta(s)=\sum 1/n^s$ 与素数定理的证明方法）。
- 硕博·泛函分析（部分谱分析中留数 / 围道积分的思想演变）。
- 数值分析（用围道积分做奇异积分的高精度求积）。

## 五、核心概念解释
**1. Cauchy–Riemann 方程**：设 $f(z)=u(x,y)+iv(x,y)$，则 $f$ 全纯的充要条件是：

$$\frac{\partial u}{\partial x}=\frac{\partial v}{\partial y},\qquad \frac{\partial u}{\partial y}=-\frac{\partial v}{\partial x}.$$

这不是"一维对称" Real Analysis 的类型限制：复可导的条件比实可导强数倍，也正因此复函数形态有令人着迷的规则性与刚性。

**2. 柯西积分定理**：若 $f$ 在单连通域 $D$ 内全纯，$C\subset D$ 为简单闭曲线，则

$$\oint_C f(z)\,dz = 0 .$$

由此出发得到柯西积分公式，构成全纯函数"内部取值由边界积分决定"的核心。

**3. 柯西积分公式与各阶导数**：

$$f(a)=\frac{1}{2\pi i}\oint_C \frac{f(z)}{z-a}\,dz,\qquad f^{(n)}(a)=\frac{n!}{2\pi i}\oint_C \frac{f(z)}{(z-a)^{n+1}}\,dz .$$

全纯函数自动无穷阶可微，这是复分析超结构性质。

**4. 方程 $\mathrm e^{i\pi}$ 与 Euler 恒等式**：

$$\mathrm e^{i\theta}=\cos\theta+i\sin\theta,\qquad \mathrm e^{i\pi}+1=0 .$$

把五个数学常数 $0,1,i,\pi,\mathrm e$ 融入同一个解析事实。

**5. 留数定理**：

$$\oint_C f(z)\,dz=2\pi i \sum_{k}\operatorname{Res}_{z=z_k}f(z) .$$

可以逼近形式上"不可能"的实积分：$\int_{-\infty}^{+\infty}\frac{dx}{1+x^2}=\pi$ 从围道积分一步拿到。

**6. Laurent 展开**：

$$f(z)=\sum_{n=-\infty}^{+\infty} c_n (z-a)^n,\qquad c_{-1}=\operatorname{Res}_{z=a} f .$$

是孤立奇点的"显微镜"。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 信号处理 | FFT 高效计算（$z$-变换与收敛域） | 数字信号分析直接依赖复解析函数、单位圆上的极点零点配置 |
| 通信工程 | Laplace / z 变换的系统稳定性 | 稳定性 = 极点分布在左半平面（连续）/ 单位圆内（离散） |
| 图形学 | 分形图像（Mandelbrot） | $z_{n+1}=z_n^2+c$ 复迭代构成经典分形 |
| 数值计算 | 围道积分 / 残数精确求积 | 深度求积方法（如 tanh-sinh）建立在复平面上 |
| 控制理论 | Nyquist 稳定性判据 | 沿闭环增加次数相似复积分，用辐角原理判定 |
| 流体 / 力学 | 二维势流（复势 $w=f(z)$） | 保角映射得出翼型绕流（Joukowski 变换） |
