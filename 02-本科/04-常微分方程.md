# 常微分方程（Ordinary Differential Equations, ODE）

> 一句话定位：研究含未知函数及其导数的方程 $F(x,y,y',\dots,y^{(n)})=0$，是连接微积分与物理建模、系统论的桥梁，也是偏微分方程与动力系统的前置课。

## 一、课程大纲
通常**一学期**开设：

**经典常微分方程**
- 一阶方程：可分离变量、齐次方程、一阶线性方程 $\frac{dy}{dx}+P(x)y=Q(x)$、Bernoulli 方程。
- 恰当方程与积分因子。
- 高阶线性方程：通解结构、特征方程法、常数变易法。
- 二阶常系数线性方程：$y''+py'+qy=f(x)$ 的齐次 / 非齐次解法。
- Lienard / Euler 方程：变系数方程的变换。
- 线性微分方程组：$\dot{\bm x}=A\bm x$、矩阵指数 $\mathrm e^{At}$ 与 Jordan 形式。
- 幂级数解与广义幂级数解：Legendre 方程、Bessel 方程。
- 定性理论初步：平衡点、相图、非线性稳定性（Lyapunov 函数）。
- Picard 存在唯一性定理：逐段常数逼近条件下的逐步迭代法公式
  $$y_{n+1}(x)=y_0+\int_{x_0}^x f(t,y_n(t))\,dt .$$

## 三、知识脉络
高等代数（特征值 $\lambda$）+ 数学分析（导数、积分、级数）→ **常微分方程**：

$$\text{一阶方程求解技巧} \Rightarrow \text{线性方程通解结构} \Rightarrow \text{特征值 }\lambda \hookrightarrow \dot{\bm x}=A\bm x \Rightarrow \text{幂级数解} \Rightarrow \text{Picard 存在唯一} \Rightarrow \text{稳定性定性理论}$$

→ 后续课程：
- 硕博·动力系统（高性能混沌 / 双曲结构 / bendixson 分析）。
- 偏微分方程（数学物理方程，本科第二门同类课程）。
- 数值分析（ODE 数值积分：Euler / RK 方法、稳定性区域）。
- 控制理论 / 机器人 ML（稳定线性控制器 + Lyapunov 分析）。
- 硕博·随机分析（Itô 微分方程是 SDE 的基础：添加噪声项 $dW_t$）。

## 五、核心概念解释
**1. 一阶线性方程的通解公式**：

$$\frac{dy}{dx}+P(x)y=Q(x)\ \Longrightarrow\ y=\mathrm e^{-\int P\,dx}\left(C+\int Q\mathrm e^{\int P\,dx}\,dx\right).$$

经积分因子 $\mathrm e^{\int P\,dx}$ 化为恰当形式，是整个 ODE 入门的第一个"万能公式"。

**2. 二阶常系数线性方程**：$y''+py'+qy=0$，设 $y=\mathrm e^{rx}$ 代入得特征方程：

$$r^2+pr+q=0 \quad\Rightarrow\quad y=C_1\mathrm e^{r_1x}+C_2\mathrm e^{r_2x}.$$

判别式 $\Delta=p^2-4q$ 的符号决定三个解结构（两个实根、重根、共轭复根）。

**3. 拉普拉斯变换解常数线性方程**（以 $\mathcal{L}$ 门径切入，工程上尤其常见）。

事实上，方程组 $\dot{\bm x}=A\bm x$（$\bm x\in\mathbb R^n$）的解定为：

$$\bm x(t)=\mathrm e^{At}\bm x_0,\qquad \mathrm e^{At}=\sum_{k=0}^{\infty}\frac{(At)^k}{k!}.$$

特征值分解 $A=P\Lambda P^{-1}$ 后 $\mathrm e^{At}=P\,\mathrm e^{\Lambda t}P^{-1}$，稳定性只要看 $\Re\lambda_i$ 的符号。

**4. Picard–Lindelöf（存在唯一性）定理**：当 $f$ 在矩形区域 $|y-y_0|\le b,\ |x-x_0|\le a$ 内对 $y$ 满足 Lipschitz 条件时，IVP 在包含 $x_0$ 的小区间内有唯一解。迭代：

$$y_{n+1}(x)=y_0+\int_{x_0}^x f(t,y_n(t))\,dt .$$

是泛函不动点定理（Banach / Schauder）的初等样本。

**5. 平衡点与线性化**：$\dot{\bm x}=f(\bm x)$，令 $\bm x^*$ 满足 $f(\bm x^*)=\bm 0$，线性化矩阵 $J=\dfrac{\partial f}{\partial \bm x}\big|_{\bm x^*}$。线性化判断：

$$\text{特征值实部} \begin{cases}<0:&\text{渐近稳定}\\ >0:&\text{不稳定}\\ =0:&\text{临界（需定性分析）}\end{cases}$$

**6. 经典例子：Logistic 方程**：

$$\frac{dy}{dt}=r y\left(1-\frac{y}{K}\right)\quad\Rightarrow\quad y(t)=\frac{K}{1+\left(\frac{K-y_0}{y_0}\right)\mathrm e^{-rt}}.$$

种群增长模型、SIR 疫情模型等传播模型的原型。
