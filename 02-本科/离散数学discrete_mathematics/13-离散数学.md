# 离散数学（Discrete Mathematics）

> 一句话定位：计算机科学的数学总纲——图论、逻辑、集合论、组合计数、递推关系——不讲连续与极限，一切对象可数；是算法正确性证明、数据结构与编译器理论的数学底座。

## 一、课程大纲
通常**两学期**或一次完整开设：

**上半段：集合 · 逻辑 · 关系**
- 命题逻辑：联结词、真值表、范式、推理规则（肯定前件 Modus Ponens 等）。
- 谓词逻辑：量词 $\forall,\exists$、自然推理系统。
- 集合与函数：映射、基数、有限 / 无限集合的对角线法证明。
- 关系：偏序、全序、等价关系与划分。
- 整数与数论初步：整除、最大公约数、Euclid 算法、模运算、同余。

**下半段：图论 · 组合 · 代数结构**
- 图论基础：$G=(V,E)$、度数、连通性、生成树、Kruskal / Prim。
- 图论应用：欧拉回路、哈密顿路径、二部图匹配、可平面性。
- 组合计数：加法原理、排列组合、容斥原理、鸽笼原理。
- 二项式定理与递推关系：$a_{n+1}+a_{n}+…$、生成函数（普通 / 指数）。
- 代数结构初步：半群 / 群 / 环 / 格与布尔代数（衔接抽象代数）。
- 树与算法：二叉树 / Huffman、Dijkstra、Bellman–Ford 等（配合算法课使用）。
- 形式语言与自动机连接（部分含 DFA、正则语言，衔接编译理论）。
- Burnside / Pólya 计数（利用群作用）+ 递推与快速幂等算法技巧（进阶）。

## 三、知识脉络
高中（集合、排列组合、逻辑推断）↔ 高等代数（矩阵 / 抽象结构）→ **离散数学**：

$$\text{命题与谓词逻辑} \Rightarrow \text{集合 / 关系 / 函数} \Rightarrow \text{计数原理与生成函数} \Rightarrow \text{图论与树} \Rightarrow \text{代数结构（群环布尔格）} \Rightarrow \text{（可选）数论与密码学衔接}$$

→ 后续课程：
- 抽象代数（把布尔格、同余推广到群环域）。
- 硕博·数理逻辑（模型论、可计算性、集合论三支）。
- 硕博·组合数学 / 图论（GTM 级别 Diestel 等）。
- 算法设计与分析、数据结构（编译器、数据库、AI 的图与逻辑推理全在里面）。
- 密码学（模运算 / 大整数 / 素数检验，涉及 ECC 群论）。

## 五、核心概念解释
**1. 德·摩根定律**（逻辑代数的基础）：

$$\neg(p\land q)\equiv(\neg p)\lor(\neg q),\qquad \neg(p\lor q)\equiv(\neg p)\land(\neg q).$$

**2. 欧拉回路的充要条件**（Königsberg 七桥问题的解决）：

$$G\ \text{连通且每个顶点的度数为偶数} \iff G \text{ 存在欧拉回路}.$$

**3. 容斥原理**：

$$\left|\bigcup_{i=1}^{n} A_i\right|=\sum|A_i|-\sum_{i<j}|A_i\cap A_j|+\dots+(-1)^{n+1}\left|\bigcup A_i \right|.$$

**4. 二项式定理**：

$$(x+y)^n=\sum_{i=0}^{n}\binom{n}{i}x^{n-i}y^i,\qquad \binom{n}{i}=\frac{n!}{i!(n-i)!}.$$

**5. 简单递推的算法事实（Fibonacci 三阶相比解法）**：

$$a_{n+2}=a_{n+1}+a_n\quad\Longrightarrow\quad a_n=\frac{\varphi^n-(1-\varphi)^n}{\sqrt 5}\ (\varphi=\tfrac{1+\sqrt 5}{2}).$$

**6. 大整数幂的"快速幂"**（复杂度 $O(\log n)$）：

$$a^n=\begin{cases}(a^{n/2})^2 & n\ \text{偶}\\ a\cdot (a^{(n-1)/2})^2 & n\ \text{奇}\end{cases}$$

是模运算 RSA 等的效率心脏。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 算法与数据结构 | 图算法（Dijkstra、拓扑排序、并查集） | 图论语言直接说明数据结构 |
| 数据库 | 关系代数与 SQL 优化 | 表（关系）之间并 / 交 / 投影连接就是集合代数 |
| 编译器 | 寄存器分配（图染色）、数据流分析 | 编译器优化的图论 / 格论工具 |
| 密码学 | RSA / ECC / 免运算 / 模算术 | 离散数论 + 抽象代数共同支撑 |
| 人工智能 / NLP | 知识图谱、约束求解 | 图表示 + 逻辑推理（SAT / SMT / CNF） |
| 网络 | 最短路径 / 生成树协议 | 路由协议（如 OSPF）的内核就是图论算法 |
