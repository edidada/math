# 数学分析（Mathematical Analysis / Calculus）

> 一句话定位：本科数学的第一门课，把高中"微积分"严格化为 $\epsilon\text{-}\delta$ 语言，是整个连续数学分支（实变、复变、ODE、PDE、微几）的地基。

## 一、课程大纲
数学分析通常分**三学期**开设（数学分析 I / II / III）：

**数学分析 I（上学期）**
- 实数与数列极限：确界原理、$\epsilon\text{-}N$ 定义，建立极限的严密基础。
- 函数连续性：$\epsilon\text{-}\delta$ 定义、闭区间连续函数性质（有界性、最值、介值、一致连续）。
- 实数完备性定理：确界原理、单调有界定理、Cauchy 收敛准则、Bolzano–Weierstrass、Heine–Borel，五大定理等价。
- 导数与微分：导数定义、求导法则、中值定理（Rolle、Lagrange、Cauchy）。
- Taylor 展开：带 Peano 余项与 Lagrange 余项的 Taylor 公式。

**数学分析 II（下学期）**
- 积分学：Darboux 上和 / 下和与 Riemann 积分 $\int_a^b f(x)\,dx$、可积条件、微积分基本定理。
- 定积分应用：面积、弧长、体积、物理应用。
- 数项级数：收敛性判别（比较、比式、根式、Abel、Dirichlet）。
- 函数项级数：一致收敛 $\sup_{x\in I}|f_n(x)-f(x)|\to 0$ 及其对连续性 / 积分 / 求导号线性交换的保证。
- 反常积分与含参变量积分。

**数学分析 III（第三学期）**
- 多元函数极限与连续：平面点集、二元函数、偏导数。
- 多元微分学：全微分、链式法则、隐函数定理、极值与 Lagrange 乘数法。
- 重积分：二重 / 三重积分、换元（含极坐标、球坐标）。
- 曲线曲面积分：Green、Gauss、Stokes 三大公式。
- 场论初步：梯度、散度、旋度；Fourier 级数展开。

## 三、知识脉络
高中数学（函数 / 数列 / 导数）→ **数学分析**：

$$\text{实数完备性} \Rightarrow \text{极限理论} \Rightarrow \text{连续（}\epsilon\text{-}\delta\text{）} \Rightarrow \text{微分中值定理} \Rightarrow \text{Riemann 积分} \Rightarrow \text{级数与一致收敛} \Rightarrow \text{多元微分学} \Rightarrow \text{重积分/曲线曲面积分}$$

→ 后续课程：
- 实变函数（Lebesgue 积分是 Riemann 积分的补完备）→ 硕博·测度论 / 泛函分析。
- 常微分方程 → 偏微分方程（数学物理方程）→ 硕博·PDE。
- 复变函数（把分析搬到 $\mathbb{C}$ 上）。
- 微分几何（把多元微积分搬到曲面上）→ 硕博·黎曼几何。
- 概率论（期望 = 积分、样本空间上的分析）→ 数理统计 → 随机过程。

## 五、核心概念解释
**1. 极限的 $\epsilon$-$\delta$ 定义**：$f$ 在 $a$ 处极限为 $A$，指任给 $\epsilon>0$ 存在 $\delta>0$，使 $0<|x-a|<\delta$ 时 $|f(x)-A|<\epsilon$。行间写法：

$$\lim_{x\to a}f(x)=A \iff \forall \epsilon>0,\ \exists \delta>0,\ 0<|x-a|<\delta \Rightarrow |f(x)-A|<\epsilon.$$

**2. 重要极限**：

$$\lim_{n\to\infty}\left(1+\frac1n\right)^n=\mathrm e .$$

它是 $\mathrm e$ 的定义来源，也是复利 / 连续增长模型的基础。

**3. 拉格朗日中值定理**：若 $f$ 在 $[a,b]$ 连续、$(a,b)$ 可导，则存在 $\xi\in(a,b)$ 使

$$f(b)-f(a)=f'(\xi)(b-a).$$

导数信息转为函数值信息，所有单调性判别、Taylor 展开的原型。

**4. Riemann 积分**：通过 Darboux 上和 $\overline{S}$ 与下和 $\underline{S}$ 定义：

$$\int_a^b f(x)\,dx \iff \inf_P \overline{S}(f,P)=\sup_P \underline{S}(f,P).$$

可积的充要条件由 Lebesgue 判据（间断点集零测）在实变函数中完成闭环。

**5. 一致收敛与极限交换**：函数列在 $I$ 上一致收敛，即

$$\sup_{x\in I}|f_n(x)-f(x)|\to 0 .$$

它保证"极限 + 连续 / 积分 / 求导"可交换，是分析学中最重要的控制手段。

**6. Newton–Leibniz 公式**：

$$\int_a^b f(x)\,dx = F(b)-F(a).$$

微分与积分互逆，构成微积分学中最核心的关系。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 机器学习 | 梯度下降的收敛性证明 | 用凸性 / Lipschitz 连续（数学分析的语言）证明 $\|\nabla f\|\!\to\!0$ 与收敛速率 |

| 信号处理 | Fourier 级数与傅里叶变换 | 一致收敛性与 Parseval 关系是 FFT / 频域分析的理论保障 |
