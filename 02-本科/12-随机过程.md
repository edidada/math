# 随机过程（Stochastic Processes）

> 一句话定位：把概率论推广到"随时间演化的随机现象"——泊松过程、马尔可夫链、平稳过程——是排队论、金融工程、通信建模、机器学习序贯模型的理论基础。（本科高年级课程）

## 一、课程大纲
通常**一学期**开设：

- 随机过程概念：概率空间上的过程族与样本路径 $\{X(t),t\ge0\}$、有限维分布、Kolmogorov 相容性条件。
- 泊松过程：计数过程 $N(t)$、独立增量、$P\{N(t)=k\}$、恒定 / 非齐次泊松过程。
- 更新过程：更新次数 $N(t)\le T$、更新定理（进阶）。
- 离散 Markov 链：状态空间、转移概率 $p_{ij}$、Chapman–Kolmogorov 方程 $p_{ij}^{(n+m)}=\sum_k p_{ik}^{(n)}p_{kj}^{(m)}$。
- Markov 链的长期性质：常返 / 瞬时、不变分布 $\pi=\pi P$、平稳分布、周期性。
- 马尔可夫链的应用样本：随机游动、Gambler's ruin、PageRank。
- 连续 Markov 链：生灭过程、出生率 $\lambda_n$ / 死亡率 $\mu_n$、CTMC。
- 平稳过程与时间序列初步：自相关函数、谱密度、遍历性。
- 生灭排队论：M/M/1 排队、Little 定律 $L=\lambda W$。
- 布朗运动与 Wiener 过程（引入，通向硕博随机分析）：$W_0=0$、均方独立增量、$W_t\sim N(0,t)$。

## 三、知识脉络
概率论（分布 + 极限定理）+ 数学分析（极限 / 积分）→ **随机过程**：

$$\text{计数过程与泊松过程 } N(t) \Rightarrow \text{离散 Markov 链 } p_{ij}^{(n)} \Rightarrow \text{平稳分布 } \pi=\pi P \Rightarrow \text{生灭过程与排队论} \Rightarrow \text{Brown 运动 } W_t$$

→ 后续课程：
- 硕博·随机分析：Itô 积分 $\int_0^t f(s)\,dW_s$、Itô 公式、SDE。
- 硕博·随机分析（Itô 积分与随机微分方程为其接班课程）。
- 金融工程（GBM 价格模型 $dS=\mu S\,dt+\sigma S\,dW$、Black–Scholes）。
- 机器学习：HMM / MCMC（Gibbs / Metropolis-Hastings 都基于 Markov 链平稳分布思想）、强化学习的 Bellman 方程源于 Markov 性 / 决策过程。
- 通信 / 网络：泊松过程 / 生灭过程天然对应报文到达 / 排队（Little 定律）。

## 五、核心概念解释
**1. 计数与泊松过程**：$N(t)$ 表示 $[0,t]$ 内事件发生次数，若强度 $\lambda$ 恒定，则：

$$P\{N(t)=k\}=\frac{(\lambda t)^k}{k!}\mathrm e^{-\lambda t},\qquad \mathrm E[N(t)]=\lambda t .$$

泊松过程是一切"稀疏到达"模型的原型（网页点击 / 网络包 / 病毒变异）。

**2. 离散时刻 Markov 链与转移**：状态空间 $S$ 上的马尔可夫链下次状态只依赖当前状态：

$$P\{X_{n+1}=j \mid X_n=i,\dots,X_0=X_0\}=P\{X_{n+1}=j\mid X_n=i\}=p_{ij} .$$

多步转移：

$$\lim_{n\to\infty} p_{ij}^{(n)}=\pi_j\quad (j\in S,\ \pi=\pi P).$$

（过渡分布收敛到平稳分布，即"运气平均"的结果。）

**3. 随机游动与赌徒毁灭（Gambler's Ruin）**：从状态 $i\ (0<i<N)$ 出发的对称 / 非对称随机游动，在到达 $N$ 之前先到达 $0$（即"破产"）的概率：

$$q_i = \frac{(q/p)^i-(q/p)^N}{1-(q/p)^N},\quad p \ne q .$$

覆盖蒙特卡洛估价、金融期权等众多模型。

**4. 生灭过程（连续时间 Markov 链）**：状态 $n$ 的出生率 / 死亡率定义：

$$\lambda_n\ \text{（出生率）}，\qquad \mu_n\ \text{（死亡率）}，\qquad P_{n,n+1}(dt)\approx\lambda_n dt .$$

M/M/1 排队的到达强度 $\lambda$、服务率 $\mu$ 下系统稳定条件 $\rho=\lambda/\mu<1$。

**5. Little 定律**（排队论中最普适的公式）：

$$L=\lambda W,$$

即平均队长 = 到达率 × 平均逗留时间，与系统分布无关（普适）。它是评估任何排队系统性能的"万能"公式。

**6. Brown 运动**：随机游动细步长的连续极限，定义为：

$$W_0=0,\quad \text{连续样本路径},\quad \text{增量独立且 } W_t-W_s\sim N(0,\,t-s)\ (s<t).$$

作为金融（股票价格）与物理（粒子扩散）模型的连续基础进入硕博随机分析。它本身是分形结构（样本路径处处连续但处处不可微）。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 机器学习 | MCMC 采样（Gibbs / Metropolis–Hastings） | 生成样本算法的基础思是马尔可夫链平稳分布 |

| 仿真 | M/M/1/cs / 离散事件系统 | Anylogic、SimPy 等仿真框架的核心原动力 |
