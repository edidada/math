# 高等代数（Advanced Algebra / Linear Algebra）

> 一句话定位：本科数学的第二门支柱课，把二次曲面几何与线性方程组抽象成线性空间 + 线性变换 + 矩阵结构，是所有"结构数学"与数值计算、机器学习的共同地基。

## 一、课程大纲
通常分**两学期**开设（高等代数 I / II）：

**高等代数 I**
- 多项式：整除、最大公因式、因式分解与 Eisenstein 判别法。
- 线性方程组与初等变换：Gauss 消元、矩阵的秩 $r(A)$。
- 行列式：$n$ 阶行列式定义与性质、Cramer 法则。
- 矩阵运算：加法、数乘、乘法 $AB$、可逆矩阵判据 $\det(A)\neq0$。
- 特征值与特征向量：$A\boldsymbol{x}=\lambda \boldsymbol{x}$、特征方程 $\det(A-\lambda I)=0$。

**高等代数 II**
- 二次型与对称矩阵：配方成标准形、$\boldsymbol{x}^{\mathsf T}A\boldsymbol{x}$、惯性定理、正定判据（各阶顺序主子式 $>0$）。
- Euclid 空间：内积、Schmidt 正交化、正交矩阵。
- 线性空间与线性变换：八条公理、基变换矩阵 $S$、过渡矩阵。
- 矩阵的相似与对角化：可对角化条件（每个特征值几何重数 = 代数重数）。
- Jordan 标准形（进阶）：$\lambda$-矩阵、初等因子。
- 最小多项式与 Cayley–Hamilton 定理：$p_A(\lambda)=\det(\lambda I-A)$，$p_A(A)=0$。
- 线性变换的像与核：维数定理 $\operatorname{rank}(A)+\operatorname{nullity}(A)=n$。

## 三、知识脉络
高中 向量 & 二次方程 → **高等代数**：

$$\text{行列式与 Gauss 消元} \Rightarrow \text{矩阵代数} \Rightarrow \text{线性空间公理化} \Rightarrow \text{线性变换} \Rightarrow \text{特征值/相似对角化} \Rightarrow \text{二次型/内积空间} \Rightarrow \text{Jordan 标准形}$$

→ 后续课程：
- 抽象代数（把"结构 + 同构"的思想推广到群、环、域）→ 硕博·交换代数 / 表示论 / 代数数论。
- 数值分析（把矩阵的乘、分解、迭代收敛变成算法）→ 硕博·数值代数。
- 实变 / 泛函（无限维线性空间：Hilbert / Banach 是线性空间理论的推广）。
- 概率统计与随机过程（协方差矩阵 $\Sigma$、马尔可夫链的转移矩阵）。
- 微分几何（切空间 $T_pM$ 是线性空间，把几何局部线性化）。

## 五、核心概念解释
**1. 矩阵乘法**：行乘列的规则，$\begin{pmatrix}1&2\\3&4\end{pmatrix}$ 即是二维平面上的一个线性映射：

$$A=\begin{pmatrix}1&2\\3&4\end{pmatrix},\quad (A\boldsymbol x)_i=\sum_{j} a_{ij}x_j .$$

**2. 特征值与特征方程**：$\boldsymbol x\neq 0$ 满足 $A\boldsymbol x=\lambda \boldsymbol x$ 当且仅当零空间非平凡：

$$\det(A-\lambda I)=0 .$$

特征值刻画线性变换的本质伸缩方向，是 PCA、解二阶线性微分方程、求平衡态的万能钥匙。

**3. 二次型的正惯性指数**：任何对称二次型都可配方成只含平方项的标准形式：

$$\boldsymbol x^{\mathsf T}A\boldsymbol x = \sum_{i=1}^{n} \mu_i y_i^2 .$$

正惯性指数 $\mu_+$ 是二次型在可逆线性变换下的本质不变量（惯性定理）：正定（$\mu_i$ 全正）对应椭球型几何，不定则对应双曲型。

**4. Cayley–Hamilton 定理**：矩阵"杀死"自己的特征多项式：

$$p_A(A)=0 .$$

可通过它由最小的多项式判断可对角化，是控制理论用来降低系统维数的核心工具。

**5. 相似对角化**：若 $A$ 可相似对角化，即存在 $P$ 使 $P^{-1}AP=\Lambda$（对角），则

$$A^k = P\Lambda^k P^{-1},\quad \Lambda^k \text{ 是对角阵的 } k\text{ 次幂}.$$

这是矩阵幂、马尔可夫链平稳分布 $\boldsymbol\pi=\boldsymbol\pi T$（极限意义下）计算的实际机制。

**6. 秩与零化度（Rank–Nullity Theorem）**：

$$\operatorname{rank}(A) + \operatorname{nullity}(A) = n .$$

维数定理：解空间维数由矩阵决定，$\dim \ker A = n - r(A)$，是给出方程组结构、编译优化中死代码消除等应用的理论基石。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 机器学习 | PCA 降维 | 中心化协方差矩阵 $\Sigma$ 的特征向量 = 主成分，$\lambda$ 取大者优先 |
| 数值计算 | SVD / QR / Cholesky 分解 | 线性代数三大分解支撑最小二乘与优化代码库（NumPy/BLAS） |
| 深度学习 | 矩阵乘 GCC 全局搜索 kernel | GPU cuDNN、TPU 全部以矩阵乘 MatMul 为最热门 kernel |
| 密码学 | Hill 密码（基于可逆矩阵） | 利用模算术下矩阵求逆与秩判断 |
| 控制理论 | 状态空间表示 | $x_{t+1}=Ax_t+Bu_t$，稳定性由 $|\lambda|<1$ 决定 |
| 图论 | 邻接矩阵 $A_G$ | $(A_G^n)_{ij} = \text{length-}n$ 路径数，是谱图论入口 |
