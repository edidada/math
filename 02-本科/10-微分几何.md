# 微分几何（Differential Geometry: Curves & Surfaces）

> 一句话定位：用微积分研究曲线与曲面的局部弯曲（曲率 / 挠率）、整体形状（Gauss–Bonnet），是通向硕博黎曼几何与广义相对论几何语言的本科台阶。

## 一、课程大纲
通常**一学期**开设（"微分几何 I：曲线与曲面"）：

- 平面与空间曲线：参数表示 $\boldsymbol r(t)$、无穷小弧长 $s=\int\|\dot{\boldsymbol r}\|\,dt$。
- Frenet 标架与公式：切 $\boldsymbol t$、法 $\boldsymbol n$、副法 $\boldsymbol b$；曲率 $\kappa$、挠率 $\tau$。
- 广义螺旋线：$\kappa$、$\tau$ 为常数的情形（圆柱螺线为其例）。
- 正则曲面：参数化 $\boldsymbol r(u,v)$、切平面 $T_pS$、第一基本形式 $I=E\,du^2+2F\,du\,dv+G\,dv^2$。
- 曲面上的曲线与测地：测地曲率、法曲率、第二基本形式 $II$。
- Gauss 曲率与平均曲率：$K=k_1k_2$、$H=\frac12(k_1+k_2)$。
- 性质："Gauss 曲率是内在不变量"的口头基础（Theorema Egregium）。
- 协变微分（Levi-Civita 联络）：由第一基本形式唯一决定的切向量场求导方式。
- 特殊曲面：可展曲面、极小曲面（如 Enneper 曲面、螺旋面、球面、平面）。
- Gauss–Bonnet 定理：

$$\int\!\!\int_M K\,dA+\sum_i \int_{\partial M} k_g\,ds = 2\pi\chi(M)$$

- Gauss 映射、Dupin 指标线（进阶）。

## 三、知识脉络
高等代数（双脚性内积、基）+ 数学分析 III（偏导数、多重积分）→ **微分几何**：

$$\text{参数曲线 } \boldsymbol r(t) \Rightarrow \text{Frenet 标架 } (\boldsymbol t,\boldsymbol n,\boldsymbol b) \Rightarrow \text{曲面参数化 } \boldsymbol r(u,v) \Rightarrow \text{第一 / 第二基本形式} \Rightarrow \text{Gauss 曲率 } K \Rightarrow \text{Gauss–Bonnet 定理}$$

→ 后续课程：
- 硕博·黎曼几何（广义黎曼流形、Lie 群作用与曲率张量）。
- 硕博·微分拓扑（莫尔斯理论、Stokes 形式广义化）。
- 硕博·代数拓扑（同调、基本群）与经典曲面分类理论（Euler 示性数、完全分类）。
- 广义相对论：时空度量 $ds^2=g_{\mu\nu}dx^\mu dx^\nu$ 的几何背景。
- 计算机图形学：可展 / 极小曲面建模、离散曲率公式。

## 五、核心概念解释
**1. Frenet 公式**：空间曲线在其自身 frame 下描述弯曲：

$$\begin{aligned}
\dot{\boldsymbol t}&=\kappa\,\boldsymbol n\\
\dot{\boldsymbol n}&=-\kappa\,\boldsymbol t+\tau\,\boldsymbol b\\
\dot{\boldsymbol b}&=-\tau\,\boldsymbol n
\end{aligned}$$

证明只用到求导与正交性；$\kappa$ 与 $\tau$ 彻底定出空间曲线的形状（相差一个刚体运动的唯一性）。

**2. 螺旋线的参数化**：

$$\boldsymbol r(t)=(a\cos t,\ a\sin t,\ bt)\quad(\kappa,\tau \text{ 为常数}).$$

同时具有非零曲率和挠率的基本例子。

**3. 第一基本形式完整性测量（内蕴测量）**：曲面上微小长度平方：

$$ds^2=E\,du^2+2F\,du\,dv+G\,dv^2,\qquad E=\boldsymbol r_u\cdot\boldsymbol r_u,\ F=\boldsymbol r_u\cdot\boldsymbol r_v,\ G=\boldsymbol r_v\cdot\boldsymbol r_v.$$

仅靠 metric $I$ 能算出的是"内在信息"（长度、面积、测地线、$K$），不需要嵌入 $\mathbb R^3$。

**4. Gauss 曲率**：

$$K=\frac{LN-M^2}{EG-F^2}=k_1k_2 .$$

球面 $K>0$、平面与柱面 $K=0$、马鞍面 $K<0$；它刻画局部是"处处鼓起"还是"两头翘起"。

**5. Theorema Egregium（Gauss 的"惊人定理"）**：虽然 $II$（第二基本形式）明显是外蕴的，但是 $K$ 其实只依赖 $I$：

$$K = \text{first fundamental 结构唯一的函数}.$$

也就是说，贴着刨床面压缩拉伸"平面的纸"的总效果由 Gauss 曲率本身决定——这就是为什么橘子皮（$K>0$）无法完美摊平在纸上。

**6. Gauss–Bonnet 定理**（整体几何核心）：

$$\iint_M K\,dA + \oint_{\partial M} k_g\,ds + \quad\sum \text{外角} = 2\pi \chi(M).$$

把局部的热度（$K$）变成整体拓扑量（$\chi$）：平面、球面、环面的整体差异。
