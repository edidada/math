# 02-本科（数学专业主流本科课程）

> 本目录按**中国大学数学专业主流课程体系**组织本科阶段核心课程，兼顾计算机行业应用视角。每门课一个 Markdown 文件，模板统一：课程大纲、主要书籍、知识脉络、专业名词（中英对照）、核心概念解释、计算机行业应用、公开课资源、习题集。

## 一、三大支柱

本科数学课程虽多，整体上围绕三大支柱展开：

| 支柱 | 代表课程 | 研究对象 | 关键词 |
| --- | --- | --- | --- |
| **连续** | 数学分析、常微分方程、复变函数、实变函数、微分几何、偏微分方程 | 极限、连续、微积分、流形上的几何 | $\epsilon\text{-}\delta$、收敛、测度、流形 |
| **离散 / 结构** | 高等代数、解析几何、抽象代数、离散数学 | 向量空间、群环域、图与组合 | 矩阵、同构、图、计数 |
| **随机** | 概率论、数理统计、随机过程 | 随机变量、抽样分布、随机过程轨道 | 分布、估计、Markov 链 |

- **数学分析**（严格化的微积分）是连续支柱的根基：ODE / 复变 / 实变 / 微几 / PDE 全部建模在它之上。
- **高等代数**（矩阵与线性空间理论）是结构支柱的根基：抽象代数把它推广到群环域，数值分析把它的算法化，离散数学把它的有限化。
- **概率论**是随机支柱的根基：数理统计是"用数据反推概率模型"，随机过程是"随时间演化的概率模型"。

## 三、本科 → 硕博 衔接

本科课程各主线分别通向 `03-硕博/` 中的研究生课程：

```text
01 数学分析 ──→ 08 实变函数 ──→ 03-硕博·测度论/实分析 ──→ 泛函分析
     └──→ 07 复变函数 ──→ 03-硕博·多复变/解析数论（进阶）
04 常微分方程 ──→ 14 偏微分方程 ──→ 03-硕博·PDE（Sobolev 空间/弱解）
02 高等代数 ──→ 09 抽象代数 ──→ 03-硕博·交换代数 / 表示论 / 代数数论
        └──→ 03 解析几何 ──→ 10 微分几何 ──→ 03-硕博·黎曼几何 / 微分拓扑
05 概率论 ──→ 06 数理统计 ──→ 03-硕博·数理统计（渐近理论）
     └──→ 12 随机过程 ──→ 03-硕博·随机分析（Itô 积分）/ Markov 过程
11 数值分析 ──→ 03-硕博·数值代数 / 凸优化 / 偏微分方程数值解
13 离散数学 ──→ 03-硕博·数理逻辑 / 组合数学 / 图论（GTM）
```

```text
大一上：01 数学分析 I、02 高等代数 I、03 解析几何
大一下：01 数学分析 II、02 高等代数 II、05 概率论（部分院系大二）
大二：  01 数学分析 III、05 概率论、04 常微分方程、13 离散数学
大三：  07 复变函数、08 实变函数、09 抽象代数、10 微分几何、11 数值分析
大三下~大四：06 数理统计、12 随机过程、14 偏微分方程（各校略有调整）
```
