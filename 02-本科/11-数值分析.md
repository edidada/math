# 数值分析（Numerical Analysis / 计算方法）

> 一句话定位：把数学分析、线性代数与 ODE 的定理变成"有限精度计算机上稳定且收敛的算法"，是科学计算、金融建模、物理仿真与机器学习工程的日用工具箱。

## 一、课程大纲
通常**一学期**开设：

- 误差与算法基础：绝对 / 相对误差、有效数字、机器舍入、数值稳定性、条件数 $\kappa(A)=\|A\|\,\|A^{-1}\|$。
- 非线性方程求根：二分法、不动点迭代、Newton 迭代 $x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}$、收敛阶 $p$。
- 线性方程组直接法：Gauss 消元、LU 分解、选主元；误差估计。
- 线性方程组迭代法：Jacobi、Gauss–Seidel、SOR；收敛判据（对角占优、谱半径 $\rho(B)<1$）。
- 特征值问题：幂法、QR 算法的思想、Rayleigh 商。
- 函数插值：Lagrange / Newton 插值、插值多项式余项、Runge 现象、分段插值。
- 曲线拟合与最小二乘：$\min_\beta \|X\beta-y\|_2$、法方程与 QR 解。
- 数值积分：梯形公式、Simpson 公式、复合公式、Gauss 求积（最大代数精度）。
- 数值微分：差商公式与 Runge 稳定性。
- 常微分方程数值解：Euler 法、改进 Euler / Heun、Runge–Kutta（RK4）、收敛与稳定域；刚性方程与隐式方法初步。
- 逼近理论知识：一致逼近、正交多项式（Chebyshev、Legendre）。

## 三、知识脉络
数学分析（Taylor 展开、收敛性）+ 高等代数（矩阵分解、特征值）+ ODE（数值积分方法）→ **数值分析**：

$$\text{误差与舍入} \Rightarrow \text{非线性方程迭代} \Rightarrow \text{线性方程组（直接法 / 迭代法）} \Rightarrow \text{特征值算法} \Rightarrow \text{插值 / 最小二乘} \Rightarrow \text{数值积分 / 微分} \Rightarrow \text{ODE 数值解}$$

→ 后续课程：
- 硕博·数值代数 / 计算数学（特征值算法加速、Krylov 子空间方法等）。
- 机器学习内情（所有模型最优化的数值方法——梯度、Hessian、条件数的实际工程问题）。
- 硕博·偏微分方程数值解（FEM / FDM / 谱方法，直接依赖本课基础）。
- 计算物理 / 科学计算仿真（光线追踪、物理引擎、电磁仿真等）。
- 组合优化与金融工程（定价 PDE 的差分离散，计算风险）。

## 五、核心概念解释
**1. Newton 迭代（平方根计算示例）**：对 $f(x)=x^2-a$ 使用牛顿迭代：

$$x_{n+1}=\frac12\left(x_n+\frac{a}{x_n}\right)\ \longrightarrow\ \sqrt a .$$

局部收敛阶为 2：$\|e_{n+1}\|\le \frac{M}{2m}\|e_n\|^2$，也就是有效数字按翻倍增长。

**2. 收敛阶的定义**：若存在正常数 $C$ 与 $p$ 使

$$\|e_{k+1}\|\le C\|e_k\|^p,\qquad e_k=x_k-x^*,$$

则 $p$ 是该迭代的收敛阶：$p=1$（线性，二分法）、$p=2$（牛顿法、Simpson 求积）。

**3. Gauss 消元与 LU 分解**：

$$A=\begin{pmatrix}1&2\\3&4\end{pmatrix}=L U,\qquad L=\begin{pmatrix}1&0\\3&1\end{pmatrix},\ U=\begin{pmatrix}1&2\\0&-2\end{pmatrix}.$$

把系统 $A\boldsymbol x=\boldsymbol b$ 变成先解 $L\boldsymbol y=\boldsymbol b$（前代），再解 $U\boldsymbol x=\boldsymbol y$（回代）。复杂度 $\frac23n^3$ 浮点乘法。

**4. 迭代解线性方程组的收敛性**：Jacobi / Gauss–Seidel 都是 $x_{k+1}=B x_k+c$ 的形式，收敛判据：

$$\rho(B)<1 .$$

**5. 复合 Simpson 求积**：

$$\int_a^b f(x)\,dx \approx \frac{h}{3}\left[f(a)+4\sum_{i\ \text{odd}} f(a+ih)+2\sum_{i\ \text{even}}f(a+ih)+f(b)\right],\qquad \text{误差 } O(h^4).$$

**6. 欧拉法与稳定性**：对 $y'=f(t,y)$，显式欧拉法 $y_{n+1}=y_n+h\,f(t_n,y_n)$；应用于模型问题 $y'=\lambda y\ (\lambda<0)$ 得稳定性区：

$$|1+h\lambda|<1\quad\Rightarrow\quad h<\frac{2}{|\lambda|}.$$

刚性 (stiff) 问题使得隐式方法（如 backward Euler）必要。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 机器学习 | 优化中的 Newton / L-BFGS | 二阶曲率（Hessian 条件数）决定收敛速度与病态问题 |
| 机器学习 | 拟合训练中的 `conjugate gradient` / preconditioner | 计算机线性代数与 Krylov 方法加速模型训练 |
| 机器人 / 自动驾驶 | 里程计与状态估计（Kalman 滤波） | 解决矩阵 $\Sigma$ 正定性、Cholesky 分解信号处理 |
| 图形学 | 刚体与柔性体（布料）仿真 | 布料求解器常用隐式积分避免数值爆裂 |
| 金融 / 风控 | Black–Scholes PDE 差分离散 | 显式格式稳定性受限，通常用隐式 / Crank–Nicolson |
| 生物 / 物理 | 分子动力学仿真 | Verlet 算法、辛积分器保持能量守恒 |
