# 泛函分析（Functional Analysis）

> 一句话定位：研究生分析的核心课——无限维空间上的线性分析，即"抽象线性代数 + 分析"：三大空间 + 四大基本定理 + 谱理论，是 PDE、算子学习与量子力学的公共语言。

先修要求（本科对应课程）：实变函数、测度论与实分析（研究生 01）、本科线性代数、点集拓扑。

## 一、课程大纲

- **第一部分 Banach 空间**：范数与对偶；四大基本定理——Hahn–Banach、开映射、闭图像、Banach–Steinhaus
- **第二部分 弱拓扑**：弱收敛、Banach–Alaoglu 定理、自反性与 Goldstine 定理
- **第三部分 Hilbert 空间**：正交基与 Riesz 表示、投影定理
- **第四部分 无界算子与谱理论**：稠定算子、伴随、自伴性；von Neumann 谱定理
- **第五部分 紧算子与 Fredholm 理论**：谱的紧算子结构、Fredholm 择一与指标
- **第六部分 算子代数入口**：$C^*$-代数、Gelfand 变换、von Neumann 代数概观
- **专题**：Bochner 积分与向量值 $L^p$；$C_0$ 半群与适定性（演化方程）；分布理论概览

- 前置本科线性代数与实变 → 本课主线：Banach/Hilbert 空间几何 → 四大基本定理 → 谱理论与紧算子 → 半群/无界算子 → PDE 弱解工具（03）、算子代数、量子力学数学基础（11 的可计算性与形式化、09 的 Feynman–Kac）

## 五、核心概念与定理

1. **Hahn–Banach 延拓定理**（保范延拓）：受控线性泛函可延拓且范数不变，对偶空间因此足够大。
   $$\|F\|=\|f\|,\qquad F\big|_M=f.$$
2. **开映射定理与 Banach–Steinhaus**：完备域间满射连续线性算子是开映射；逐点有界的算子族在第二纲空间上必一致有界。
   $$\sup_{\alpha\in A}\|T_\alpha\|<\infty.$$
3. **Riesz 表示定理**：Hilbert 空间上的连续线性泛函由内积唯一给出：
   $$f(x)=\langle x,u\rangle,\qquad \|f\|=\|u\|.$$
4. **von Neumann 谱定理**：自伴（或正常）算子由谱测度给出函数演算：
   $$T=\int_{\sigma(T)} \lambda\,dE(\lambda),\qquad f(T)=\int_{\sigma(T)} f(\lambda)\,dE(\lambda).$$
5. **紧算子谱理论与 Fredholm 择一**：紧算子的非零谱点是特征值；$K$ 紧时 $I-K$ 可逆性与核维数由齐次方程决定。
   $$\dim\ker(I-K)=\dim\ker(I-K)^*.$$
6. **Gelfand 变换（$C^*$-代数）**：交换 $C^*$-代数同构于 $C(\Delta)$，Gelfand 空间 $\Delta$ 即极大理想空间；谱半径公式 $\displaystyle r(T)=\lim_n\|T^n\|^{1/n}$。
