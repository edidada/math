# 概率论（Probability Theory）

> 一句话定位：随机支柱的第一门课——把随机现象公理化为概率空间上的测度论式结构，为统计、随机过程以及机器学习 / 人工智能的所有概率推理打下基础。

## 一、课程大纲
通常**一学期**开设：

- 随机事件与样本空间：事件运算、古典概率、几何概率。
- 概率公理与性质：$P(\Omega)=1$、可加性、$P(A\mid B)=\dfrac{P(AB)}{P(A)}$。
- 条件概率与独立性：全概率公式、Bayes 公式。
- 一维随机变量：分布函数 $F(x)$、离散型（二项、泊松、几何）与连续型 ($\rho(x)$ 密度、均匀、指数、正态)。
- 随机变量函数的分布：变换法 $Y=g(X)$、$\rho_Y(y)=\rho_X(g^{-1}(y))\,\lvert(g^{-1})'(y)\rvert$。
- 多维随机变量：联合分布、边缘、条件分布；卷积公式。
- 随机变量的数字特征：期望 $\mathrm E[X]$、方差、协方差、矩。
- 大数定律：$P\!\left(\left\lvert\dfrac{S_n}{n}-\mu\right\rvert>\epsilon\right)\to 0$ 及其不同形式（Bernoulli、Chebyshev、Khinchin、Kolmogorov 强大数定律）。
- 中心极限定理：CLT $\dfrac{S_n-n\mu}{\sigma\sqrt n}\xrightarrow{d}N(0,1)$。
- 特征函数与依分布收敛（简要引入，为极限定理做准备）。
- 鞅的初步概念（选讲）：条件期望的简单性质。

## 三、知识脉络
数学分析（积分 + 极限）↔ 组合并**概率论**：

$$\text{概率空间 } (\Omega,\mathcal F,P) \Rightarrow \text{随机变量与分布 } F(x) \Rightarrow \text{期望 } \mathrm E[X]=\int x\,dF \Rightarrow \text{矩 / 方差} \Rightarrow \text{大数定律} \Rightarrow \text{中心极限定理}$$

→ 后续课程：
- 数理统计（用数据反推分布；频率一致性由大数定理支撑）→ 硕博·数理统计 / 渐近理论。
- 随机过程（把随机变量序列扩展成随时间演化的模型）→ 硕博·随机分析 / Markov 过程。
- 实变函数 / 测度论：Kolmogorov 公理化本质上是对测度论式的概率重写，在实变之后更清晰。
- 硕博·泛函分析（分布含有 Fourier 变换表示，本质为特征函数）。
- 信息论 / 编译器优化（熵 $H(X)=-\sum p_i\log p_i$、生成式模型的交叉熵损失）。

## 五、核心概念解释
**1. Kolmogorov 公理**：样本空间 $\Omega$，事件集 $\mathcal F$，概率测度 $P$ 满足：

$$P(\Omega)=1,\quad 0\le P(A)\le 1,\quad P\!\left(\bigcup_i A_i\right)=\sum_i P(A_i) \ (A_i \text{ 互不相交}).$$

**2. 条件概率与 Bayes 公式**：

$$P(B\mid A)=\frac{P(AB)}{P(A)},\qquad 
P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)},\qquad
P(B)=\sum_i P(B\mid A_i)P(A_i)\ \text{（全概率公式）}.$$

Bayes 公式是机器学习贝叶斯方法的核心。

**3. 期望与方法的方差**：

$$\mathrm E[X]=\int_{-\infty}^{+\infty}x\,\rho(x)\,dx,\qquad
\operatorname{Var}(X)=\mathrm E[X^2]-(\mathrm EX)^2 .$$

**4. 重要分布**：

- 二项分布：$P\{X=k\}=\binom{n}{k}p^k(1-p)^{n-k}$。
- Poisson 分布：$P\{X=k\}=\dfrac{\lambda^k}{k!}\mathrm e^{-\lambda}$（稀有事件，$\lambda=n p$ 极限）。
- 正态分布：
  $$\rho(x)=\frac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).$$

**5. 切比雪夫不等式与 Chebyshev 大数定律**：

$$P\{|X-\mu|\ge \epsilon\}\le \frac{\sigma^2}{\epsilon^2}, \qquad
P\left(\left|\frac{S_n}{n}-\mu\right|>\epsilon\right)\to 0 .$$

前者给出对大概率的上界，后者担保样本均值依概率收敛到总体均值。

**6. 中心极限定理**：若 $X_i$ 独立同分布，$\mathrm E X_i=\mu$，$\operatorname{Var}(X_i)=\sigma^2<\infty$，则：

$$\frac{S_n-n\mu}{\sigma\sqrt n}\ \xrightarrow{d}\ N(0,1).$$

这是统计学假设检验与置信区间、蒙特卡洛实验室纪录标准误差的根基。

## 六、计算机行业应用
| 领域 | 具体应用 | 说明 |
| --- | --- | --- |
| 机器学习 | 概率图模型（Naive Bayes / HMM） | 直接利用 Bayes 公式与变量独立近似 |
| 蒙特卡洛模拟 | $\pi$ 估值、积分抽样 | 由大数定律 $\frac{S_n}{n}\to\mathrm E[X]$ 保证收敛 |
| 机器学习 | 交叉熵损失 / Softmax | $\mathcal L=-\sum y_i\log p_i$，源自最大似然 |
| 信息论 / LLM |困惑度与熵 | $H(P)=-\sum p_i\log p_i$，语言模型评价指标 |
| 随机算法 | Monte Carlo Tree Search / Randomized algorithms | 用概率分布驱动搜索（AlphaGo） |
| 区块链 | Baby 验证 | PoW 挖矿成功概率 $1-(1-p)^k$ 等指数模型 |
