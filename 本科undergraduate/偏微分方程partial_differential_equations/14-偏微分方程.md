# 偏微分方程（Partial Differential Equations / 数学物理方程）

> 一句话定位：研究含偏导数的实体微分方程——波动、热传导、位势三大类——把物理现象变成可算可证的数学问题；是本科分析与 PDE 数值方法、硕博 Sobolev 空间理论的收尾主干课。

## 一、课程大纲
通常**一学期**（"数学物理方程"）开设：

- 方程导引：波动方程、热方程、Laplace 方程的物理来源；定解问题（初值 / 边界 / 初边混合）。
- 二阶线性方程分类：双曲型、抛物型、椭圆型；特征线与标准型化简。
- 一维波动方程：D'Alembert 公式 $u(x,t)=\frac12[\phi(x+at)+\phi(x-at)]+\frac1{2a}\int_{x-at}^{x+at}\psi(\xi)\,d\xi$。
- 分离变量法：对热方程 $u_t=a^2u_{xx}$、波动、Laplace；特征函数展开。
- Fourier 级数与本征值问题：正弦 / 余弦展开、Sturm–Liouville 理论引论。
- 极坐标 / 柱面 / 球面坐标下的 Laplace 方程：Legendre 多项式与球谐函数（特殊函数初步）。
- 积分变换法：Fourier 变换求解初值问题；Green 函数思想（进阶）。
- 位势方程：Dirichlet / Neumann 问题、调和函数的最大值原理。
- 解的存在唯一性与适定性：能量积分法（波动 / 热方程的能量估计）。
- Cauchy–Kovalevskaya 定理（定理表述，证明可选）。

## 三、知识脉络
数学分析 III（多元微积分）+ 常微分方程（分离变量后的 ODE）+ 复变函数（调和函数工具）+ Fourier 级数 → **偏微分方程（数学物理方程）**：

$$\text{物理三大方程（波动 / 热 / 位势）} \Rightarrow \text{定解条件（初值/边界）} \Rightarrow \text{D'Alembert 公式} \Rightarrow \text{分离变量法} \Rightarrow \text{Fourier 级数展开} \Rightarrow \text{Green 函数与调和函数} \Rightarrow \text{能量估计与适定性}$$

→ 后续课程：
- 硕博·PDE（Evans GTM：Sobolev 空间 $H^1$、弱解、椭圆正则性、双曲 / 抛物理论）。
- 数值分析 PDE 数值解（有限差分 / 有限元 / 谱方法）→ 硕博·FEM 理论。
- 硕博·随机分析（热方程 $u_t=\frac12u_{xx}$ 与布朗运动生成元、Feynman–Kac 公式）。
- 金融工程 / 医学影像 / 计算力学（对波动 / 热方程的动力模拟与仿真）。
- 频域信号处理（Fourier 变换的 PDE 应用基础）。

## 五、核心概念解释
**1. 波动方程与 D'Alembert 公式**：一维波动方程 $u_{tt}=a^2u_{xx}$，初速度 $\phi$、初速度 $\psi$ 的一般解：

$$u(x,t)=\frac{\phi(x+at)+\phi(x-at)}{2}+\frac{1}{2a}\int_{x-at}^{x+at}\psi(\xi)\,d\xi .$$

展示"左右行波叠加"的物理直觉，不需任何 $u$ 的任意与边界条件。

**2. 热传导方程与分离变量法**：$u_t=a^2u_{xx}$，令 $u=X(x)T(t)$：

$$\frac{T'}{a^2T}=\frac{X''}{X}=-\lambda \quad\Longrightarrow\quad T=\mathrm e^{-a^2\lambda t},\ X=\sin\sqrt{\lambda}x .$$

与边值条件一起得到 Fourier 正弦级数表达。

**3. 拉普拉斯方程与平均值性质**：调和函数在圆心处的取值等于圆周平均：

$$u(P)=\frac{1}{2\pi}\int_0^{2\pi}u(P+r\cos\theta,\ r\sin\theta)\,d\theta .$$

也就是 Laplace 方程解的"无损光滑"表达。

**4. Poisson 方程（基本解 / Green 函数）**：

$$\Delta u=f\quad\text{在}\ \mathbb R^3\ \text{的基本解}\ T(r)=\frac{1}{4\pi r}.$$

每个点的"源"都以距离倒数的方式贡献到 $u$——这正是电磁学中库仑定律的数学形式。

**5. 适定性 (Hadamard 三条件)**：解为"存在、唯一、对数据连续依赖"：

$$\|u(t)\|\le C\,(T)\,\|u_0\| .$$

任何数值方法的书全都遵循这一结构框架，才能给出稳定、收敛的算法。

**6. 能量（积分）法**：对波动方程定义能量

$$E(t)=\frac12\int_0^L (u_t^2+a^2u_x^2)\,dx,$$

证明 $\dfrac{dE}{dt}=0$，代入边界零条件得唯一性。这是 Banach / inner-product/energy standpoint 的起点。
