# 数学学习体系（高中 → 本科 → 硕博）

> 按培养阶段组织的数学知识库。每门课一个 Markdown 文件 + 独立习题集文件，内含：大纲、主要书籍、知识脉络、专业名词（中英对照）、概念解释、计算机行业应用、公开课资源、习题集（含答案与解析）。公式统一使用 **KaTeX** 语法（`$...$` 行内、`$$...$$` 行间），可在 Typora / Obsidian / VSCode 预览中直接渲染。

## 目录结构

```text
math/
├── 高中人教版high_school_pep/    # 人教A版（2019课标），按册-章节划分
├── 本科undergraduate/          # 数学专业主流本科课程
└── 硕博postgraduate/          # 研究生阶段课程 + 论文库（经典 & 2026.10 前沿）
```

## 三个阶段概览

| 阶段 | 文件夹 | 核心脉络 | 课程数 |
| --- | --- | --- | --- |
| 高中（人教A版） | `高中人教版high_school_pep/` | 集合 → 函数 → 三角/向量/复数 → 立体与解析几何 → 数列/导数 → 统计与概率 | 18 |
| 本科 | `本科undergraduate/` | 数学分析 + 高等代数两大支柱 → ODE/复变/概率 → 实变/抽象代数/微分几何 → 数值/随机过程/离散数学 | 14 |
| 硕博 | `硕博postgraduate/` | 测度论/泛函分析/PDE → 几何（黎曼、拓扑）→ 代数（交换代数/数论/表示论）→ 随机分析/优化/逻辑 | 11 + 论文库 |

## 学习路线速览

```text
高中：函数 / 不等式 / 数列
   │
   ├── 本科·数学分析 ──→ 实变函数 ──→ 硕博·测度论与实分析 ──→ 泛函分析
   │        └──→ 常微分方程 ──→ 偏微分方程（数学物理方程）
   ├── 本科·高等代数 ──→ 抽象代数 ──→ 硕博·交换代数 / 表示论 / 代数数论
   │        └──→ 拓扑 ──→ 硕博·代数拓扑
   ├── 本科·概率论 ──→ 数理统计 ──→ 随机过程 ──→ 硕博·随机分析
   └── 本科·数值分析 / 离散数学 ──→ 硕博·凸优化 / 数理逻辑
```

## 使用说明

- 每个课程文件中的骨架是稳定的，正文由**占位符 `TODO`** 标注待补充内容，逐步填充。
- **习题集独立成文件**：每门课配套《`{编号}-{课程名}-习题集.md`》（如 `14-数列-习题集.md`），题目、答案与解析统一在此维护（v0.2：每门课 6–8 道基础、3–5 道进阶含证明思路或研究导向、计算机实践题，均附答案）。
- 硕博阶段：课程文件第九节已与 `papers/` 两份文件逐条联动；`papers/经典论文.md` 的 DOI/出处已联网核查（v0.2，Crossref/NUMDAM 交叉验证）。
- 习题集部分每门课都预留了基础题、进阶题、计算机实践题三个分区。
- 硕博阶段另有 `硕博postgraduate/papers/` 目录：**经典论文** 与 **2026 年 10 月前沿论文**（含联网检索到的最新成果）。

> 本库为初始骨架版本（v0.1），内容由浅入深陆续完善。
