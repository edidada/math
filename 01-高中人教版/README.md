# 01 高中阶段（人教A版·2019）

## 一、阶段定位

本目录为数学知识库的高中阶段子库，共收录 **18 个模块**，覆盖高中数学全部主干内容。教材依据教育部《普通高中数学课程标准（2017年版2020年修订）》，采用**人民教育出版社·人教A版（2019）**，对应必修第一册、必修第二册、选择性必修第一册、第二册、第三册共五册教材、八章（第1—8章，跨册连续编号）。各模块文件按统一模板编写，含课程大纲、主要书籍、知识脉络、专业名词（中英对照）、核心概念解释、计算机行业应用、公开课资源与习题集（习题部分目前为占位，待逐步补充）。

## 三、学习主线与阅读顺序

- 必修第一册（集合—不等式—函数—指对幂—三角）打牢函数主线，是全阶段的地基。
- 必修第二册（向量—复数—立体几何—统计—概率）引入代数与几何的工具，并初步建立随机思维。
- 选择性必修第一册（空间向量—直线与圆—圆锥曲线）完成解析几何主线。
- 选择性必修第二册（数列—导数）完成离散与微分的两条收束线。
- 选择性必修第三册（计数原理—随机变量—成对数据）完成概率统计主线。
- 建议顺序：01→02→03→04→05→06→07→08→09→10→12→13→14→15→11→16→17→18（11 可与 08 对比学习）。

## 四、高中→本科衔接说明

高中阶段是本科数学学习的直接基础，衔接关系如下：

1. **函数主线 → 数学分析（高等数学）**：模块 02、03、04、05 中的函数概念、定义域值域、单调性奇偶性，经模块 15 的导数（瞬时变化率 = 极限定义）通向数学分析的极限论、微分学与级数。
2. **代数主线 → 高等代数与解析几何**：模块 06、11 的向量和矩阵化思想（线性运算、基底分解、坐标表示）直接对应高等代数的线性空间；模块 07 复数与平面向量的对应是复分析的第一课；模块 12、13 的解析几何是空间解析几何与线性代数几何应用的雏形。
3. **随机主线 → 概率论与数理统计**：模块 09、10 的抽样与古典概型、模块 16 的计数原理、模块 17 的条件概率与随机变量（期望方差、二项分布、正态分布）、模块 18 的回归与独立性检验，构成概率论与数理统计的全部前置直观。
4. **逻辑与集合 → 离散数学与近世代数**：模块 01 的集合语言、量词与充分必要条件是证明语言的基础，衔接离散数学、数理逻辑与抽象代数。
