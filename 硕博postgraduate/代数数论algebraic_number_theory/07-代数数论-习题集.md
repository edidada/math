### 基础题（核心定理复现/应用）

1. 求 $\mathbb Q(\sqrt{-5})$ 的类群并说明其类数 $=2$。

   **解析**：$\mathcal O_K=\mathbb Z[\sqrt{-5}]$、判别式 $D=-20$。Minkowski 界

   $$B_K=\frac{2!}{2^2}\Big(\frac{4}{\pi}\Big)^{1}\sqrt{20}=\frac12\cdot\frac{4}{\pi}\cdot 4.47\approx 2.85,$$

   故只需检查 2 上的素理想：$-5\equiv3\pmod 4$ 分歧式，$(2)=\mathfrak p^2$、$\mathfrak p=(2,1+\sqrt{-5})$，$N(\mathfrak p)=2$。若 $\mathfrak p$ 主，需 $x^2+5y^2=2$ 有整数解——不存在（$|x|\le1$ 时验证），故 $\mathfrak p$ 非主类。又 $\mathfrak p^2=(2)$ 主 ⟹ $[\mathfrak p]$ 阶恰为 2，$\operatorname{Cl}(K)\cong\mathbb Z/2$、$h_K=2$。

2. 用 Minkowski 界证明 $\mathbb Q(\sqrt{7})$ 的类数为 1。

   **解析**：$\mathcal O_K=\mathbb Z[\sqrt7]$、$D=28$（全实，$r_2=0$）：

   $$B_K=\frac{2!}{2^2}\sqrt{28}\approx2.65.$$

   唯一需检算的素是 2：$(2)=\mathfrak p^2$、$\mathfrak p=(2,\sqrt7)$、$N(\mathfrak p)=2$。主性验证：$3+\sqrt7\equiv\sqrt7\equiv0\pmod{\mathfrak p}$ ⟹ $(3+\sqrt7)\subseteq\mathfrak p$；而 $N(3+\sqrt7)=9-7=2=N(\mathfrak p)$，理想范数相等 + 包含 ⟹ $(3+\sqrt7)=\mathfrak p$ 主。故每个类都有范数 $\le B_K<3$ 的主代表 ⟹ $h_K=1$。

3. （Dirichlet 单位定理应用）对 $K=\mathbb Q(\sqrt5)$ 写出 $\mathcal O_K^\times$ 的结构并求基本单位。

   **解析**：$\mathcal O_K=\mathbb Z\big[\frac{1+\sqrt5}{2}\big]$、$r_1=2$、$r_2=0$，单位秩 $r_1+r_2-1=1$，故

   $$\mathcal O_K^\times=\{\pm\varepsilon^n:\ n\in\mathbb Z\}\ \cong\ \mu_K\times\mathbb Z,\qquad \mu_K=\{\pm1\}.$$

   黄金比 $\varepsilon=\frac{1+\sqrt5}{2}$：$N(\varepsilon)=\frac{1+\sqrt5}{2}\cdot\frac{1-\sqrt5}{2}=\frac{1-5}{4}=-1$，且 $\varepsilon>1$，故可作为基本单位（其 $\mathbb Z$-幂张满秩 1 的自由部分；全范数 $\pm1$ 分裂到 $N=+1$ 指标 2 子群 $\langle\varepsilon^2\rangle$ 上）。

4. （判别式与分歧）用 Dedekind 判别式定理确定 $\mathbb Q(\zeta_5)$ 的分歧素数，并写出 $D_K$。

   **解析**：分圆域 $\mathbb Q(\zeta_p)$ 的判别式公式

   $$D=\big(-1\big)^{\frac{p-1}{2}}p^{\,p-2};$$

   对 $p=5$：$D=5^{3}=125$（正号：$\frac{p-1}{2}=2$ 偶）。只有 $p=5$ 分歧（$5\mid D$），其余素数非分歧——即"判别式的素因子集合＝分歧素数集合"这一 Dedekind 定理的行业版用法，分圆情形与 $\zeta_p$ 的极小判别一致。

5. （Hensel 引理数值应用）求 $\mathbb Z_7$ 中 $\sqrt2$ 的前三位 7-adic 数字。

   **解析**：$\bmod\ 7$：$3^2=9\equiv2$，初值 $x_0=3$（$f'(3)=6\not\equiv0$ ⟹ Hensel 单根唯一提升）。逐位：设 $x=x_0+7k$，则

   $$x^2=9+42k+49k^2\equiv2+42k\ \ \pmod{49},$$

   需 $42k\equiv-7\pmod{49}$ ⟹ $6k\equiv6\pmod7$ ⟹ $k=1$，$x\equiv10\pmod{49}$（验算 $10^2=100=2+2\cdot49$ ✓）。再提一位：$x=10+49m$，

   $$x^2=100+980m+2401m^2\ \equiv\ 100+294m\ \pmod{343},$$

   需 $294m\equiv-98\pmod{343}$ ⟹ $42m\equiv35\pmod{49}$ ⟹ $6m\equiv5\pmod7$ ⟹ $m\equiv2\pmod7$，得 $x\equiv108\pmod{343}$（验算 $108^2=11664=2+34\cdot343$ ✓）。故 $\sqrt2=3+1\cdot7+2\cdot7^2+\cdots\in\mathbb Z_7$。

### 研究导向题

1. 阅读类域论主定理（Artin 互惠律）的条件部分，推导二次域的 Kronecker–Weber 特例。

   **思路提示**：CFT 主定理由 Idele 类群（旧型：射线类群）与 Abel 扩张的 Galois 群建立正合对应；二次情形的特化路线：次数 2 的 Abel 扩张对应 $\mathbb Z/2$ 型射线类群的商，互惠律在此退化为二次互惠律的 Hilbert 符号表述——再用 Gauss 和的符号计算把每条射线类群陈述翻译回分圆域的子域，即闭合 Kronecker–Weber（每个 Abel 数域含于某个 $\mathbb Q(\zeta_m)$）。写作时先按局部（Hilbert 符号）二次版本验证，再全局搬运。
   **文献导航**：Neukirch《Algebraic Number Theory》第 VI–VII 章（全局/局部类域论）；Cox《Primes of the Form $x^2+ny^2$》第 8–9 章（CFT 查看 + Kronecker–Weber 特例）；原始文献 Artin（1927，Abh. Math. Sem. Hamburg）见 `../papers/经典论文.md`「三、代数」条目。

2. 把类数公式具体化到虚二次域，与解析上关于 class number of $\mathbb Q(\sqrt{-d})$ 的研究衔接（读 Heegner/Stark 类问题）。

   **思路提示**：虚二次情形（$r_1=0$、$r_2=1$、$w$ 为单位根个数）类数公式退化为

   $$\operatorname*{Res}_{s=1}\zeta_K(s)=\frac{2\pi\,h_K\,R_K}{w\sqrt{|D|}},$$

   单位秩 $r_1+r_2-1=0$ 给 $R_K=1$，残数由 Dirichlet $L(1,\chi_D)$ 显式给出（如 $h(-3)=1$、$h(-163)=1$ 的特值）。研究衔接：Gauss 类数问题（哪些 $-d$ 使 $h=1$：Heegner 数共 9 个）与 Stark–Heegner 定理的解析解决路线；把"虚二次类数 1 的判别式枚举"写成五页小综述最合适。
   **文献导航**：Washington《Introduction to Cyclotomic Fields》第 4 章（$L$-值与类数）；Cox《Primes of the Form $x^2+ny^2$》第 11 章（Heegner/Stark）；类域对应源流见 `../papers/经典论文.md`「三、代数」的 Artin（1927）互惠律条目；前沿侧另见 `../papers/前沿论文-2026-10.md` 中 openai/math 手稿库的"霍奇猜想 CM 情形"条目（算术几何视角）。

### 计算机实践题

1. 用 Python/Pari（`cypari2`）计算 $K=\mathbb Q(\sqrt{-71})$ 的类群、判别式和 regulator；或用 Lean4 形式化"二次域判别式整除结构"。

   **步骤要点**（3–5 步）：
   1. `cypari2` 建域：`from cypari2 import Pari; P = Pari(); b = P.bnfinit("x^2 + 71", 1)`（或 `P("bnfinit(x^2+71)")`），建立 $K=\mathbb Q(\sqrt{-71})$ 的类域基数据。
   2. 取判别式 `b.disc()`：因 $-71\equiv1\pmod4$，$\mathcal O_K=\mathbb Z\big[\tfrac{1+\sqrt{-71}}{2}\big]$、$D_K=-71$（数值核验；$-71$ 恰为 Heegner 数之一，预期 $h_K=1$）。
   3. 取类数与类群结构：`b.cyc()`（循环分解，预期平凡群）与 `b.clgp`；再用 Minkowski 界手工对照

   $$B_K=\frac{2!}{2^2}\cdot\frac{4}{\pi}\cdot\sqrt{71}\approx 5.36$$

   （逐个检算范数 $\le 5$ 的素理想的主性，交叉验证 $h_K=1$）。
   4. regulator（虚二次恒 $=1$，无单位自由部分）确认：`b.reg()` 输出 1，与 Dirichlet 单位定理相符（$r_1+r_2-1=0$）。
   5. 进阶（Lean4）：形式化"二次域判别式整除结构"的示意 statement：

   ```lean
   -- 示意 statement：二次域判别式 ≡ 0 或 1 (mod 4) 且其素因子刻画分歧素
   -- （正式名字以当前 mathlib 为准，见 `Mathlib/NumberTheory/QuadraticBasic.lean` 等）
   example {d : ℤ} (hsq : d ≠ 0) (h : d.sqfree) :
       (quadraticDiscriminant d).gcd 4 ∈ ({0, 1} : Set ℤ) := by
     sorry -- 思路：$\mathbb Z[\sqrt d]$ 或 $\mathbb Z[(1+\sqrt d)/2]$ 两种整基的行列式
   ```

   （示意题目：以 mathlib `NumberTheory.NumberFields`/`QuadraticRing` 命名为准。）
