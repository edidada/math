# 硕博postgraduate：研究生阶段数学知识库

> 本目录是数学知识库的「硕博研究生阶段」部分：11 门核心课程，按四大方向组织，配套 `papers/` 论文索引。最后更新：2026-10-23。

## 方向划分

- **分析**：测度论与实分析、泛函分析、偏微分方程、随机分析与马尔可夫过程
- **几何拓扑**：微分流形与黎曼几何、代数拓扑
- **代数**：交换代数与同调代数、代数数论、群表示论
- **计算与逻辑**：凸优化与最优控制、数理逻辑与模型论

## papers/ 目录说明

- `papers/经典论文.md`：按四大方向分节的经典论文清单（作者、标题、年份/出处、一句话贡献）。
- `papers/前沿论文-2026-10.md`：2026 年 8–10 月人工智能与数学交叉重大事件及 arXiv 动态快照，各课程文件「研究前沿速览」条目与之一一呼应；其中部分结论（尤其是 Navier–Stokes 爆破等争议项）引用前请务必按该文件内的免责声明核实。

> 阅读/使用建议：先按本科阶段知识库（`本科undergraduate/`）补齐先修，再按方向并行推进课程；每份课程文件末尾附习题占位与论文指引，均可在 `papers/` 中找到原文线索。
